# JalebiScoreboard

Sidebar scoreboard for JALEBI SMP (Paper 1.21+, Vault for money).

- `/scoreboard` (`/sb`) opens a GUI to toggle: scoreboard, money, kills, deaths, playtime, shards
- `/shards <give|take|set|check> <player> [amount]` (permission `jalebi.shards.admin`)

## Build
Push to GitHub, then open the **Actions** tab, pick the latest run and download the
`JalebiScoreboard` artifact. Or locally: `mvn package` (Java 21).
